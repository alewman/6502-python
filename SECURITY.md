# Security Policy

## Supported versions

This project is currently published as the 0.1.x alpha release line. Security
fixes are provided for the latest released 0.1.x version only. Earlier 0.1.x
releases, development checkouts, and unreleased commits are not supported; users
should first upgrade to the current PyPI release.

| Version | Supported |
| --- | --- |
| Latest 0.1.x release | Yes |
| Earlier 0.1.x releases | No |
| Unreleased development versions | No |

## Reporting a vulnerability

Please report suspected vulnerabilities privately through the
[GitHub private vulnerability reporting form](https://github.com/alewman/6502-python/security/advisories/new).
This keeps the report visible only to the project maintainers and GitHub until a
coordinated disclosure is agreed.

Include the affected version, a clear description of the impact, and concise
steps to reproduce the issue. Do not include passwords, access tokens, private
keys, or other credentials in the report. If sensitive reproduction material is
needed, say so in the private report and wait for a maintainer to arrange a safe
exchange.

Please do not open a public issue, discussion, pull request, or commit for an
unfixed security vulnerability. Allow the maintainers time to investigate and
prepare a fix before public disclosure.

## Ordinary bugs and feature requests

For non-security defects, questions, documentation corrections, and feature
requests, use the project's [public issue tracker](https://github.com/alewman/6502-python/issues).
Public issues are not an appropriate channel for vulnerabilities because their
details may be immediately visible to others.
